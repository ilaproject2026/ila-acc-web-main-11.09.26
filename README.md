# ILA Global — Corporate Website

A professional, modern corporate landing page for **ILA Global** (International Learning Alliance), built with React, Tailwind CSS, and Lucide icons.

## Features

- **Responsive navigation** with organized dropdown menus for all service categories
- **Hero section** with key statistics and CTAs
- **Education & Training** — German Language, Ausbildung, Medical/DemTest Prep
- **Jobs & Career Services** — Doctor to Driver placements, AI Resume Upload & Match
- **Visa Services** — Business, Tourist, Student, Job Seeker visas + AI Document Processor
- **Earn While Learn** — IT and Import-Export career pathways
- **Rewards Program** — tiered loyalty system
- **About & Contact** — company info and contact form
- **Unified Portal Login** — secure login modal supporting Student, Employee, Team, and Employer dashboards

## Getting Started

```bash
cd C:\Users\rafia\Projects\ila-global
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- [React 19](https://react.dev/) + TypeScript
